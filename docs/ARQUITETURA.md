# 🧱 Arquitetura do projeto

## Visão geral

O sistema de gestão de estoque do SESI Lab será desenvolvido com **Java no backend** e **Angular no frontend**, seguindo a diretriz de **monólito modular** definida pela equipe.

Essa abordagem permite organizar responsabilidades em módulos coesos e evoluir a aplicação de maneira incremental, mantendo uma estrutura acessível para quem está começando.

## Princípios de organização

- **Responsabilidades claras:** cada módulo deve concentrar funcionalidades relacionadas.
- **Simplicidade:** soluções compreensíveis e adequadas ao estágio do projeto.
- **Colaboração:** convenções e contratos devem ser compartilhados com a equipe.
- **Qualidade incremental:** revisão de código, testes e melhoria contínua.
- **Aprendizado:** decisões técnicas são oportunidades para mentoria e desenvolvimento dos juniores.

## Áreas funcionais do sistema

O escopo inicial contempla acesso de usuários, catálogo de itens, movimentações de estoque, histórico, alertas e administração. Essas áreas orientam a compreensão do domínio e o planejamento das atividades; não representam, por si só, uma estrutura de pacotes já implementada.

## Fluxo de desenvolvimento

1. Selecionar uma issue preparada no backlog.
2. Compreender o fluxo funcional e os critérios de aceite.
3. Implementar a mudança com escopo reduzido.
4. Submeter um pull request e compartilhar como validar.
5. Participar da revisão e incorporar feedback.

A arquitetura deve apoiar a entrega do sistema e, principalmente, **o crescimento técnico dos participantes**.
