# 📚 Documentação — SouJava Junior

Bem-vindo à documentação do **Sistema de Gestão de Estoque do Espaço Maker do SESI Lab**.

O projeto é uma experiência colaborativa de desenvolvimento, voltada principalmente ao **crescimento técnico e profissional dos juniores**, com acompanhamento de pessoas mais experientes.

## Conteúdos

- [Arquitetura](ARQUITETURA.md) — organização técnica e princípios de modularidade.
- [Design e componentes](DESIGN-SYSTEM.md) — prototipação, consistência visual e evolução da interface.
- [Registro da reunião de 13/10/2026](REUNIAO-2026-10-13.md) — decisões e próximos passos comunicados ao time.

## Trabalho colaborativo

As atividades são acompanhadas pelas [issues](https://github.com/SouJavaBrasilia/SesiLab/issues) e pelo [Kanban](https://github.com/orgs/SouJavaBrasilia/projects/1). Use esses espaços para acompanhar tarefas, compartilhar entregas e participar das revisões.
